# Atividade 05 - Site sobre paternidade
O projeto Paternidade é um site desenvolvido com o objetivo de compartilhar informações e dicas que possam ajudar pais e responsáveis durante as diferentes fases da criação de um filho. O site apresenta conteúdos sobre as etapas da paternidade, recomendações de filmes, séries, documentários e livros relacionados ao tema, além de orientações sobre os cuidados básicos com bebês, como alimentação, higiene, sono seguro e vacinação.
O site foi desenvolvido utilizando HTML e CSS, com o objetivo de colocar em prática os conhecimentos adquiridos nas aulas. Seu design utiliza cores suaves em tons pastel, buscando transmitir uma sensação de acolhimento e tranquilidade, procurando reunir informações úteis de maneira simples, organizada e visualmente agradável.
